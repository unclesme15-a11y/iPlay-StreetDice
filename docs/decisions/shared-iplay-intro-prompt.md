# Shared iPlay startup ident

Use the same approved iPlay metal-plate logo and cyan color in every iPlay game. The Unity mobile client already loads `iPlay/Branding/iplay_app_icon` and the selected `iPlay/Audio/IPLAY_LOGO_VOICE_STING`; its current fade/scale intro is a starting point, not the finished metal-plate effect. The voice sting is identical to the user's `02-iplay-dark-futuristic.mp3` reference. Do not redraw or restyle the symbol.

## Base prompt for both games

Create a short Unity-rendered startup ident using the existing iPlay dark brushed-metal plate and cyan symbol. The first app frame must match Android's static dark launch background, with no white or black flash between native startup and Unity. From near-darkness, a narrow cyan light traces the outer edge of the plate. The existing iPlay symbol illuminates from its center outward. The plate gives one small, weighty forward strike, synchronized to a short metal/card-slam impact and the existing iPlay voice sting. Cyan pulses once around the border, then the logo holds briefly and fades directly into the game's 18+ screen or home screen. Keep the whole ident brief, legible on a phone, and free of extra words, casino imagery, or a substitute logo.

Use the existing image if separated art is not ready. Preferred reusable transparent layers are a 2048x2048 plate, cyan outline, iPlay symbol, and restrained glow. Animate the layers in Unity so both games preserve the same mark, color, and voice while allowing small game-specific accents. The native Android splash uses a matching static frame; it is not a second logo animation.

## Street Dice variation

Before the plate strike, add two quick, grounded dice clacks. Each clack produces one brief cyan pip-shaped glint along the lower metal edge; the glints vanish as the plate lands and the main iPlay symbol lights up. Do not add oversized flying dice, a felt table, or a second logo. The dice accent should be visible enough to identify this game but subordinate to the shared iPlay ident. The iPlay voice sting remains the same as in the card game.

## Implementation boundary

This is the approved direction for future Unity intro work, not a claim that the layered assets or new animation have been produced. The Street Dice camera and wagering changes are independent of this intro. Dice Calling is a separate setting and remains disabled until the user records the number calls.
